# 현재 브랜치의 GitHub 이슈 확인

현재 git 브랜치 이름에서 이슈 번호를 추출하고, 해당 GitHub 이슈의 상세 정보를 가져옵니다.

## 실행

```bash
~/.claude/scripts/issue.sh
```

## 출력 형식

조회된 이슈 정보를 다음과 같이 정리해서 보여주세요:

### 이슈 #{번호}: {제목}

- **상태**: {open/closed}
- **작성자**: {author}
- **라벨**: {labels}
- **담당자**: {assignees}

#### 본문
{body 내용}

#### 코멘트
코멘트가 있으면 시간순으로 정리:
- **{작성자}** ({날짜}): {코멘트 내용}

---

이 정보를 바탕으로 현재 작업의 컨텍스트를 파악하고, 필요한 작업을 안내해주세요.
