# Visual QA Playbook

`/visual-qa`의 세부 테스트 단계와 안전 규칙이 필요할 때만 보는 문서.

목표:

- 변경된 프론트엔드 라우트의 기능/시각/UI 품질을 검증

핵심 단계:

1. 환경 감지
2. 변경 파일 감지
3. 영향 라우트 매핑
4. 테스트 URL 생성
5. 브라우저 기반 데이터 수집
6. `visual-qa-analyzer` 서브에이전트 분석
7. `tmp/visual-qa-report.md` 생성

수집 항목:

- 콘솔 에러
- 네트워크 4xx/5xx
- DOM 상태
- 인터랙션 결과
- 반응형/스크롤 시각 데이터

중요 규칙:

- 브라우저 조작은 순차 수행
- 기존 데이터 수정/삭제 금지
- `[QA-TEST]` 접두어가 있는 테스트 데이터만 CRUD 대상
- 로그인/로그아웃 자동 수행 금지

실패 처리:

- 탭 무효, 네비게이션 타임아웃, JS 실행 에러는 제한적으로 재시도
- 연속 3회 실패 시 사용자에게 계속 여부 확인
